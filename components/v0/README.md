# V0 Components

This directory contains components generated by V0 by Vercel.

## How to Add Components

1. Generate component in V0
2. Copy the code
3. Create a new `.tsx` file here
4. Import and use in your pages

## Example

```tsx
// components/v0/VenueCard.tsx
export default function VenueCard({ venue }) {
  return (
    <div className="border rounded-lg p-4">
      <h3>{venue.name}</h3>
      <p>{venue.location}</p>
    </div>
  );
}
```

Then use it:
```tsx
// app/venues/page.tsx
import VenueCard from '@/components/v0/VenueCard';

export default function VenuesPage() {
  return <VenueCard venue={data} />;
}
```

See `V0_INTEGRATION_GUIDE.md` in the root directory for detailed instructions.
